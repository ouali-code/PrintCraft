# PrintCraft Studio — portfolio

Démo front-end d’un atelier d’impression et de reprographie fictif, conçue avec React et Vite.

## Lancer le projet

```bash
npm install
npm run dev
```

Pour générer la version de production :

```bash
npm run build
```

## Avertissement

Projet de démonstration conceptuel réalisé pour un portfolio. Ce site n'est affilié à aucune entreprise réelle.
